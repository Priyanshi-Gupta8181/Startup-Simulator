# 🚀 Startup Simulator (Riddlers Escape Room)

A futuristic and interactive **Startup Simulation Web App** built using **React + Vite**.
This app lets users generate, simulate, and analyze startup ideas with a visually rich UI and dynamic experience.

---

## 🌟 Features

* 🧠 AI-based Startup Idea Generator
* 🎯 Multi-step simulation (Idea → Market → Pitch → Outcome)
* 📊 Dynamic market analysis metrics
* 💼 Investor reaction simulation
* 🎉 Confetti animation for success
* 🎨 Modern glassmorphism UI
* ⚡ Smooth animations & transitions
* 📱 Responsive design

---

## 🛠️ Tech Stack

* ⚛️ React
* ⚡ Vite
* 🎨 CSS
* 🎉 canvas-confetti

## 🚀 Getting Started

### 🔹 Method 1: Using Terminal

Install dependencies:

```
npm install
```

Run project:

```
npm run dev
```

Open in browser:
http://localhost:5173/

---

### 🔹 Method 2: One Click Run (No Coding)

👉 Simply double-click:

```
run.bat
```

✔ This will automatically:

* Start the server
* Open your project in browser

---

## 🎮 How It Works

1. Click **Start Journey**
2. Configure startup (name, budget, risk)
3. Generate startup idea
4. Analyze market metrics
5. Pitch to investors
6. Get final outcome (Unicorn 🦄 / Stable 📈 / Failed 💀)
